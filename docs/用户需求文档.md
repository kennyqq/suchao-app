# 苏超智能化指挥中心 - 用户需求文档

> **项目信息**
> - 项目名称：江苏移动苏超智能化指挥中心
> - 项目版本：v1.0.0
> - 目标用户：江苏移动网络保障团队、赛事指挥中心
> - 部署场景：1920x1080 大屏展示

---

## 1. 项目概述

### 1.1 项目背景

江苏超级联赛（简称"苏超"）是江苏省举办的足球联赛赛事。为确保赛事期间网络通信畅通、用户体验优质，需要构建一套智能化指挥调度系统，实现对赛前、赛中、赛后全周期的网络态势感知、资源调度和效果评估。

### 1.2 项目目标

构建基于 **React + Vite** 的数据可视化大屏应用，实现：
- 赛前：球迷迁徙态势感知与预测
- 赛中：5G-A网络实时监控与智能调度
- 赛中：场馆内部微观监控与根因诊断
- 赛后：全量评估复盘与持续优化建议

### 1.3 核心 Slogan

> **"一张网，火一座城"** —— 宏观溯源  
> **"看得清态势，防得住隐患"** —— 全局防御

## 3. 详细功能需求

### 3.1 P0 宏观溯源视图

#### 3.1.1 中央地图区
**需求描述**：展示球迷从全国各地/江苏省内前往南京的迁徙态势

**功能要求**：
- 支持「全国视图」和「江苏视图」两种模式切换
- 迁徙飞线效果：带有箭头的流动线条，颜色表示流量强度（红>黄>蓝>灰）
- 城市点位：南京以金色脉冲效果突出显示
- 地图可缩放、平移交互
- Tooltip：悬停显示城市名和具体人数

**数据来源**：信令/计费系统的用户位置分析数据

#### 3.1.2 左侧面板

**模块1：苏超开幕倒计时**
- 显示距离下一届苏超开幕的剩余天数和小时数
- 动态倒计时更新

**模块2：城市文旅引流指数**
- 当前指数数值（如：35,241人）
- 较平日均值增长率（如：+120%）
- 计算公式说明

**模块3：球迷来源地 TOP8**
- 全国/省内两种维度切换
- 柱状图展示各城市来源人数排名
- 前三位高亮显示（金色）

#### 3.1.3 右侧面板

**模块1：交通枢纽压力监测**
- 监测对象：奥体地铁站、南京南站、南京站、禄口机场
- 显示指标：压力指数、今日客流量、平日客流量对比
- 进度条可视化压力程度
- 状态标识：高压力（红色）、中等压力（黄色）

**模块2：文旅大数据分析**
- 实时游客总数（近3天）
- 平均停留时长
- 热门打卡点 TOP5 排名
- 各景点游客数和增长率

### 3.2 P1 全局态势视图

#### 3.2.1 中央3D地图区
**需求描述**：基于高德地图 + AntV L7 的南京奥体中心周边网络态势数字孪生

**功能要求**：
- 3D 地图展示，包含建筑物、道路等地理信息
- 基站点位标记（主站/子站区分，不同高度柱状图）
- 四色防御圈区域高亮（核心/商业/交通/安检口）
- 人流动线可视化（进场/散场不同颜色）
- 基站点击：弹出详情模态框

**数据更新频率**：
- 基站状态：实时（30秒内）
- 人流动线：随时间轴联动

#### 3.2.2 左侧面板

**模块1：5G-A 资源与韧性**
- 网格展示资源概况：
  - 5G 站点数量（如：48个）
  - 智能板数量（如：6个）
  - 3CC 载波数量（如：48个）
  - 应急车数量（如：2辆）

**模块2：PRB 负载监控**
- 整体负载百分比（如：56%）
- 各热点场景负载详情：
  - 元通地铁入口
  - 南看台 F区
  - 奥体北门检票口
  - 内场 VIP区
- 正常/告警状态颜色区分

**模块3：智能运维终端（CoPilot）**
- 滚动日志展示
- 日志类型及颜色标识：
  - success（绿色）：操作成功
  - info（灰色）：普通信息
  - warn（黄色）：警告
  - alert（红色）：告警
  - ai（青色）：AI 智能决策
- 自动向上滚动动画
- 在线状态指示

#### 3.2.3 右侧面板

**模块1：KQI 业务指标**
- 2x2 网格展示关键指标：
  - 总流量（GB）+ 趋势图
  - 语音话务量（Erl）+ 趋势图
  - 平均吞吐（Mbps）+ 趋势图
  - 时延（ms）+ 趋势图
- 每个指标显示当前值、单位、变化趋势
- 迷你折线图展示历史趋势

**模块2：智能体告警监测**
- 告警总数统计
- 高优先级告警数量标记
- 告警列表（可滚动）：
  - 告警级别（高/中/低/提示）
  - 告警标题
  - 影响区域
  - 发生时间（相对时间）
- 告警卡片颜色区分级别

### 3.3 P2 场内微观视图

#### 3.3.1 中央场馆舞台
**需求描述**：场馆内部平面图/热力图展示

#### 3.3.2 左侧面板

**模块1：分层分级用户（金字塔漏斗图）**
- 三层金字塔展示用户构成：
  - 顶层：场馆包用户（金色，最少）
  - 中层：全球通金卡（银色）
  - 底层：普通用户（青色，最多）
- 各层显示人数和占比
- 底部显示用户总数

**模块2：放号评估智能体**
- 容量使用率缺口环形图（如：60%）
- 状态标签：建议推广（绿色）/ 容量告警（红色）
- 未来30分钟预测折线图：
  - 历史数据（青色实线+圆点）
  - 预测数据（黄色实线+菱形点）
  - 当前时刻标记
- 预测峰值显示

**模块3：终端能力分析**
- 左侧：UE Logo 支持率环形图（如：60%）
- 右侧：TOP5 终端排行
  - 品牌+型号
  - 用户数量
  - 5G-A 支持标识
- 排名 medal 颜色区分（金/银/铜）

#### 3.3.3 右侧面板

**模块1：分层分级体验（雷达图）**
- VIP用户 vs 普通用户 六维对比：
  - 下行速率
  - 语音清晰
  - 视频卡顿
  - 直播上行
  - 低时延
- 金色区域：VIP体验
- 青色区域：普通用户体验

**模块2：基础业务保障（App KQI Grid）**
- 2x2 网格展示关键 App 体验：
  - 微信消息（时延）
  - 抖音播放（画质）
  - 网页首屏（体验）
  - 扫码支付（成功率）
- 绿色标识：业务正常
- 显示具体指标值

**模块3：智能根因诊断**
- 告警列表展示：
  - 告警级别（高/中）
  - 告警标题
  - 详细描述
  - 发生时间
- 点击可查看根因分析详情
- 颜色区分：红色（高危）、黄色（中危）

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|-----|------|
| 页面首屏加载时间 | < 3秒 |
| 数据接口响应时间 | < 500ms (P95) |
| WebSocket延迟 | < 100ms |
| 数据新鲜度 | 告警 < 3s, 指标 < 30s |
| 并发支持 | 支持 50+ 大屏同时在线 |

### 4.2 界面要求

- **分辨率适配**：专为 1920x1080 大屏设计
- **色彩风格**：赛博朋克风格（深蓝底色 + 青色/金色高亮）
- **动效**：适度使用 Framer Motion 实现入场/交互动画
- **响应式**：移动端仅支持基础浏览

### 4.3 可靠性要求

- 支持离线缓存（地图数据本地存储）
- 接口失败时显示兜底数据
- 关键告警支持 WebSocket 实时推送

## 5. 数据需求

### 5.1 数据源说明

| 数据类型 | 数据来源 | 更新频率 |
|---------|---------|---------|
| 迁徙数据 | 信令/计费系统 | T+5分钟 |
| 基站状态 | 网管系统 | 实时（30秒内） |
| KQI指标 | 话单/DPI系统 | 1-2分钟 |
| 告警数据 | 故障管理系统 | 实时推送 |
| 人流动线 | 信令定位 | 时间轴联动 |

### 5.2 接口清单

详见后端接口文档，主要接口包括：

- `GET /api/v1/p0/migration` - 迁徙数据
- `GET /api/v1/p1/global` - P1全局数据
- `GET /api/v1/p2/venue` - 场馆数据
- `GET /api/v1/p3/evaluation` - 评估数据
- `GET /api/v1/alarms/active` - 实时告警
- `GET /api/v1/timeline` - 时间轴数据
- `WebSocket /ws/alerts` - 告警实时推送
